# humanoid-war-elephant-character-3d-model
3D humanoid war elephant character model created in Maya, with final render preview.

This project represents an older character modeling work focused on anatomy, proportions, and overall silhouette design. The character blends humanoid features with elephant-inspired elements, designed as a fantasy or war-themed character.

The repository includes:
- The final Maya character model
- A single final render preview image

**Note:**  
The original Substance Painter project and texture files are no longer available. The render provided is a simple preview intended to showcase the character’s overall look and design.
